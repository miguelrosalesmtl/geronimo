geronimo installed as release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

1. Watch the reports stack come up:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

2. First install only -- bootstrap reports-backend's service account (see the
   plan's §4 / apps/reports-backend README): grant an admin role to a ci-bot
   user, mint an API key scoped to testruns.create, then store it:
     kubectl create secret generic {{ include "geronimo.reportsApiKeySecretName" . }} \
       --from-literal=REPORTS_API_KEY=<the minted key> -n {{ .Release.Namespace }}

3. Trigger the e2e suite on demand:
   kubectl create job --from=job/{{ include "geronimo.fullname" . }}-e2e-run \
     {{ include "geronimo.fullname" . }}-e2e-manual-$(date +%s) -n {{ .Release.Namespace }}

4. Browse results:
   kubectl port-forward svc/{{ include "geronimo.fullname" . }}-reports-dashboard 8080:{{ .Values.reportsDashboard.service.port }} -n {{ .Release.Namespace }}
   open http://localhost:8080
